## 1. FORMAL MATHEMATICAL PROOF
Let $L_i$ represent raw candidate logits generated by a transformer model over vocabulary $V$. The characteristic policy function $\Phi(v_i) \in \{0, 1\}$ is evaluated via Z3 SMT first-order logic:

$$\hat{L}_i = L_i + \log \Phi(v_i)$$

When an input contains an adversarial or policy-violating token state ($\Phi(v_i) = 0$):

$$\hat{L}_i = L_i + \log(0) = L_i - \infty = -\infty$$

$$\lim_{\hat{L}_i \to -\infty} \exp(\hat{L}_i) = 0 \implies P(v_{\text{invalid}}) = 0.00000\% \quad \blacksquare$$
